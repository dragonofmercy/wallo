# Changelog

All notable changes to Wallo are listed here. The format follows [Keep a Changelog](https://keepachangelog.com) and versions follow [Semantic Versioning](https://semver.org).

## [Unreleased]

- Faster Apply, using less memory with large images
- Smoother preview while changing settings
- Error messages can be copied with a right-click

## [1.1.2] - 2026-10-14

- Keep wallpaper applied no longer shows an error at startup when an image is on a network drive that is not connected yet
- A missing image is shown with its name in red

## [1.1.1] - 2026-10-13

- Text in dialogs can no longer be selected by accident

## [1.1.0] - 2026-10-13

- New Options window, opened from the main window or the tray menu
- Keep wallpaper applied: Wallo puts your wallpaper back when monitors change or another program replaces it
- Automatic update checks can be turned off
- About window with the version and links to GitHub
- Deleting a profile asks for confirmation inside the app

## [1.0.0] - 2026-10-13

- Different image on each monitor, one image across all monitors, or the same image everywhere
- Profiles you can switch from the tray icon
- Scale, rotate, move, blur and mirror each image, with a live preview
- One-click alignment to an edge, a corner or the center
- Start with Windows
- Automatic updates
